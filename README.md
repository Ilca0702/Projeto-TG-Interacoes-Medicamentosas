# Projeto de Teoria dos Grafos - Interações Medicamentosas

## Descrição
Projeto desenvolvido na disciplina de Teoria dos Grafos com o objetivo de representar e analisar interações entre medicamentos utilizando grafos.

Os medicamentos são representados pelos vértices e as interações entre eles pelas arestas. O grafo utilizado é não orientado e ponderado, sendo os pesos relacionados aos níveis de gravidade das interações.

## Dados
Os dados utilizados foram obtidos a partir da base DDInter.

O grafo utilizado no projeto possui:
- 80 vértices
- 220 arestas
- Peso 1: interação leve
- Peso 2: interação moderada
- Peso 3: interação grave

## Implementação
A aplicação foi desenvolvida em Python utilizando lista de adjacências para representação do grafo.

O programa permite:
- leitura e gravação do arquivo do grafo;
- inserção e remoção de vértices;
- inserção e remoção de arestas;
- visualização do grafo;
- análise de conexidade.

## Arquivos
- `main.py`: código-fonte da aplicação.
- `grafo.txt`: dados utilizados para construção do grafo.
- `projetoTG_parte2_templateRelatorio.pdf`: relatório final do projeto.
